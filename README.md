# Venkateshwara Wood Press Oils

A modern, responsive website for Venkateshwara Wood Press Oils - showcasing pure, organic, and cold-pressed oils.

## Project Structure

```
Venkateshwara-Wood-Press-Oils/
├── index.html          # Homepage
├── about.html          # About us page
├── products.html       # Products showcase
├── contact.html        # Contact form
├── style.css          # Styling
├── script.js          # JavaScript functionality
├── images/            # Product images
│   ├── shop.jpg
│   ├── groundnut-oil.jpg
│   ├── sesame-oil.jpg
│   ├── coconut-oil.jpg
│   ├── sunflower-oil.jpg

```

## Features

- **Responsive Design** - Works seamlessly on desktop, tablet, and mobile devices
- **Accessible** - Built with accessibility in mind (semantic HTML, keyboard navigation)
- **Modern UI** - Clean and professional design with smooth animations
- **Product Showcase** - Display all products with descriptions and pricing
- **Contact Form** - Easy way for customers to get in touch
- **Fast Loading** - Optimized for quick page loads

## Pages

1. **Home (index.html)** - Landing page with hero section and featured products
2. **About (about.html)** - Company information and mission
3. **Products (products.html)** - Complete product catalog with prices
4. **Contact (contact.html)** - Contact information and contact form

## Getting Started

1. Clone this repository
2. Open `index.html` in your web browser
3. Add your product images to the `images/` folder
4. Update contact information in `contact.html`
5. Customize colors and styling in `style.css`

## Deployment

You can deploy this website using GitHub Pages:

1. Go to your repository settings
2. Scroll to "Pages" section
3. Select `main` branch as the source
4. Your site will be available at: `https://yourusername.github.io/Venkateshwara-Wood-Press-Oils/`
